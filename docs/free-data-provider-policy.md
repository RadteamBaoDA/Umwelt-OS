## 4. P2/P3 record and transport constants

Shared parsing: preserve JSON numeric lexical precision with Decimal-aware JSON decoding, not float-first decoding then Decimal(str(float)). Numeric strings use Decimal directly. Reject bool,NaN,infinity and malformed number; explicit provider null/empty-string means missing only when documented, never0. Current WorldDataMeasurement stores `value:float|None`; convert once at this documented schema boundary after finite checks, retain canonical decimal text in bounded provider_fields for monetary/FX values and USGS magnitude/coordinates where needed. Check the converted float remains finite. A decimal too large for finite float is invalid rather than infinity. Currency/unit/symbol are source semantics, not inferred aliases.

Source_fields below are bounded allowlist recommendations, not instructions to mirror arbitrary response bodies. WorldDataMeasurement.provider_fields is currently max12 scalar entries: keep upstream provider list as a bounded delimiter-separated string or amend the owner DTO explicitly; never inject an array into a scalar field. Structured provider envelope.world_data provider must match envelope.provider; generic REST/client ReceiveBatch cannot mint trusted metadata. Document/Observation owner APIs retain source-generation/workspace/scope/version lineage. Connector code never writes those tables directly.

World Bank pagination is a concrete unresolved brief/protocol seam: `per_page=3` caps page size, not dataset scope. For the approved endpoint validate pages and persist exact bounded continuation through ingestion; each accepted page has its own terminal request receipt, next request only after terminal acknowledgement, each send debit1. An alternative finite pilot endpoint is adding `mrv=3` to explicitly request latest3annual periods, but it is a controller-approved scope change, not an automatic mapper assumption. Do not use MRNEV silently because that hides recent nulls required by P3. API docs do not promise caller-controlled sort, so do not treat page1 as guaranteed newest solely by array order.

HN fan-out is bounded transport inside one admitted request, not provider pagination:1list+at most10sequential items, each fresh fence/debit. Native/managed REST pagination hidden inside n8n HTTP nodes is unsupported; shared Python send gate applies everywhere.

Provider min cache/freshness (CoinPaprika5–10min,USGS feed1min,ECB working-day,Frankfurter mostlydaily) is distinct from our chosen TTL.
