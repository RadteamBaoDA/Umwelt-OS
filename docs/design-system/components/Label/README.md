# Label

A 13px / 650 field label (`label` type style) in `text`.

Source: `apps/web/src/components/ui/label.tsx` — native `<label>` with `.label`.

- Consumer provides `htmlFor` and translated text in sentence case ("From date", "Occurrence precision").
- Stack above the control in `.field`; for checkbox and radio rows put the label to the right.
